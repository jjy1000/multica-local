## Lessons / prevention

1. **Stall 风险**: 复杂 SSE loop 改动容易 stall(executor watchdog 600s),应**最小化 scope + helper 优先 + 后续 commit 接主路径**(commit `139159638` 仅 helper,`c82a12e05` 才接 SSE 循环)。
2. **Memory file 漂移**: CLAUDE.md 引用 `0.2.97-daemon-autostart-regression.md`,但 memory store 不存在,导致 daemon fix 状态失实。Lesson:memory index 应跟随 CLAUDE.md 引用定期 reconcile。
3. **Working tree dirty carryover**: 跨 session 留下的 dirty working tree(create-issue.tsx + 半成品 writer.go)会污染新 agent。Lesson:每次 ship 前必须 `git status --short` + 决定 stash / commit / discard。
4. **Auto-bump version**: ship chain 不自动 bump version,需要手动 `Edit apps/desktop/package.json` + commit `chore(release)`。Lesson:CLAUDE.md 已规定"Bump apps/desktop/package.json only",但 ship chain 没把这个 step 自动化 — follow-up 是 ship-mac.sh 加 pre-flight version check。
