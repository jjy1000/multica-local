## Lessons

1. **MUL-6399 made 109b67790 obsolete.** The status filter category heading crash (Base UI `Menu.GroupLabel` THROW without `Menu.Group` ancestor) only fires because `DropdownMenuLabel` is rendered — once MUL-6399 drops the category headings, the `DropdownMenuLabel` is never rendered, the THROW never fires, the wrap fix becomes unnecessary. This is a generalizable lesson: **when porting a fix, check whether the prerequisite the fix was built for still exists in your port.** If the surface state has moved past the bug, the fix can be skipped wholesale. (This is the structural regression-guard pattern in reverse — instead of preventing reversion, preventing re-importation of obsolete fixes.)
2. **Fork's `view-store.ts` is missing the `viewBaseline` concept.** Multiple upstream commits assume it exists (`109b67790`, `109b67790` again via `fixedTitle`). When fork's UI grows to need this concept (e.g. a "save current filter as view" feature), it will need to be ported from upstream with the same pattern. Track in CLAUDE.md "Deferred" so the next port has the signal.
3. **`use-issue-status-branches.ts` (the surface/ directory) is fork's biggest MUL-6243 backlog.** The fork never built the `surface/` directory under `packages/views/issues/` (verified empty). MUL-6409 (cards in category column) is the first commit that requires this surface; until it lands, any future MUL-6243 incremental that touches `use-issue-status-branches.ts` will SKIP-NO-SURFACE. Future-port candidate: port `use-issue-status-branches.ts` + its tests as a separate audit (~300-500 LOC), then re-evaluate MUL-6409 + any later MUL-6243 incremental.
4. **The "StatusOption.category" field is the kind of small extension that breaks type-only port.** Fork's pre-state omitted it because all callers stayed inside `group.options.map` where category was implicit. Porting MUL-6399 (which iterates the flat `options` array) required extending the interface. Pattern: when porting a commit that collapses a grouped structure into a flat one, check whether downstream callers had omitted fields they could derive from the group context.
