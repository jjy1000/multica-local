## Why this batch

用户实测三个代理协作断流症状(JYF-490 派工无人认领 / JYF-497 红蓝对抗被
blocked 无人接管 / JYF-496 实验室报告不可见不回传)。三路取证(DB 队列/
活动/评论 + daemon/renderer 日志 + 双 Explore agent 深挖 + 产物端点专项)
定位四个根因:

1. **mention 正则过严**(JYF-490):`MentionRe` 只认 `[@Label](mention://…)`
   规范形状,主管派工评论的 `**@名** ([mention://agent/id])` 变体全漏 →
   零任务行,领队空等 received。修:`ParseMentions` 加 `bareMentionRe` 裸
   URL 容错;坑:`all` 分支必须排在 hex 类前(无尾锚,否则 `all/all` 的 a
   被 `[0-9a-fA-F-]+` 吃掉解析出假 id)。
2. **状态→blocked 零触发**(JYF-497):worker 置 blocked 是交还信号但无人
   接收。修:`notifyParentOfChildBlocked`(无 stage barrier,cancelled/
   backlog/member 父闸镜像 done 路径,自唤醒按 MUL-2808 允许)。
3. **done 父抑制闸吞掉委托回传**(JYF-489/496):Helper 派工后即关父,子完
   成是唯一唤醒源。修:done 父 + done 子照常唤醒;cancelled 子/父仍抑制。
4. **UI 交付链三连带**:报告被 `hides_deliverable_in_issue_timeline` 整体
   藏掉(DB/API 都有、UI 零渲染);产物端点 0.5.114 schema 漂移 →「暂无产
   物」;runtime 评论无 WS publish + artifact 摘要评论漏 WorkspaceID。
