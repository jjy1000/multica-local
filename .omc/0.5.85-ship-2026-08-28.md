## Known Stability Surfaces (new entry)

- **`node_modules/turbo` may be deleted between sessions.** Symptom:
  `pnpm typecheck` → `MODULE_NOT_FOUND ... node_modules/turbo/bin/turbo`.
  Happened once between 0.5.84 ship (12:30) and 0.5.85 ship gate (15:49)
  — 3 hours later, no agent or user action in between. **Recovery**:
  `CI=true pnpm install --frozen-lockfile` (28 s, restores full state).
  The non-TTY abort is the reason for the `CI=true` prefix — pnpm refuses
  to remove the modules dir interactively. Consider adding a `pnpm
  typecheck` integrity check to `scripts/ship-mac.sh` that runs before
  step 4 (build), so the gate fails fast instead of mid-build.
