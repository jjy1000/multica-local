## Structural regression guard

`server/pkg/agent/launch_test.go::TestOnlyLaunchGoLogsAgentCommandArgs` is the load-bearing test for MUL-6362. It AST-walks every `.go` file in `pkg/agent` and fails on any `Debug/Info/Warn/Error/Log/LogAttrs` call carrying `args`/`argv`/`agent command` literal or `args`/`cmdArgs`/`argv`/`cmd.Args` identifier. The test passed on this commit (all 13 runtime files now use `logAgentCommand`), and will fail if a future contributor accidentally reverts to the unredacted `b.cfg.Logger.Info("agent command", "exec", execPath, "args", args)` pattern. This is the kind of regression guard that prevented the 0.5.36 MUL-6243 port wholesale-adoption trap (memory: `0.5.36-mul6243-ui-closeout-2026-08-18.md`).

## Lessons

1. **Pre-port fork file inventory catches SKIPs before they waste time.** The 23-commit scan flagged 5 as port candidates (CVE, MUL-6362, MUL-6330, MUL-6264, MUL-6394); deep-eval against fork's actual files found MUL-6264 and MUL-6394 have NO corresponding surface in fork. Net: 2 commits caught and routed to CLAUDE.md deferred as NO-SURFACE before any code was written. The lesson generalizes — **always grep fork's file tree before claiming a cherry-pick applies**, especially for files added in the last 2-3 months where fork's divergence may be larger.
2. **The "structural regression guard" pattern from MUL-6362 launch_test.go is reusable.** AST-walking the package dir for forbidden logger calls (with `args`/`argv`/`agent command` literal OR `args`/`cmdArgs`/`argv`/`cmd.Args` identifier) is the most robust defense against accidental reversion. Cheap to write (~50 LOC), runs in <100ms, catches both direct reverts and renamed-equivalent reverts. Pattern candidates: any future commit that introduces a single-bounded log-redaction-style contract.
3. **`Config.LaunchPrefix nil` is acceptable when the platform has no custom-runtime-profile fixed-args plumbing.** The `trustedAgentCommandPositionals` helper handles `len(c.LaunchPrefix) == 0` correctly via `originalLen := len(c.LaunchPrefix) + len(source.invocationArgs)` — the suffix-match still works, just with a stricter equivalence check. Future custom-runtime-profile code can set LaunchPrefix without re-plumbing the helper.
4. **Fork docs structure divergence is OK to SKIP for redaction-related docs.** The MUL-6362 docs Callout adds user-facing guidance about credentials in `custom_args`. Fork's docs section structure diverged from upstream's anchor; the SKILL.md update carries the agent-facing contract (more important than user docs since agents see `custom_args` more often than users), and the server-side redaction is the load-bearing defense. SKIP docs is a fork-local fork, not a contract violation.
