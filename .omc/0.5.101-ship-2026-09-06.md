The upstream `ListDaemonWorkspaces` / `GetDaemonWorkspace` functions do not exist on fork. B.5 is dormant until fork gains those functions through some other route.

The wholesale dbstats.go swap was attempted, then reverted to keep the PR's diff surgical. ## Lessons (rolled into future work)

1. **Deep-dive before committing to scope.** The original coarse evaluations undersold MUL-7008 by 3×. Agent research claims were wrong on this one. Per CLAUDE.md "Surgical Changes", sticking to actual scope (not planned scope) is the right call.
2. **Pre-existing test failures are not blockers if they're pre-existing.** Verified the 2 repocache co-author hook failures against 0.5.100 HEAD before flagging — both fail identically before this PR.
3. **Pre-existing build break is not a regression.** Verified fork's HEAD `dbstats.go` already imported `dbstartup` (missing package) before this PR — `cmd/server` was unbuildable before this PR.
4. **Don't wholesale-swap files when the fork has partial pre-ports.** The wholesale dbstats.go swap was attempted, then reverted because the fork pre-ported the MUL-7016 B.4 dbstats.go state with `fmt` import + simpler structure. Wholesale would have introduced the `dbstartup` import (missing package) as a new failure. Surgical edits respect partial pre-ports.
