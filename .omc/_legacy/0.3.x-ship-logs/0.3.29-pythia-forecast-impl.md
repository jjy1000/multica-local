Previous: 0.3.28
Schema migrations: **+0** (无破坏性迁移)

## Headline

0.3.29 在 0.3.24 forecast SSE 基础上,把"pythia_oracle 标签的 Issue
→ 论坛/订阅/报告"这条回路闭合。Issue 选择 "Pythia 预测引擎"
lab tag 后,前端通过新的 `POST /api/experimental/pythia-oracle/
forecast/issue` 取回绑定该 Issue 的预测报告;报告直接渲染在
`/experimental/pythia` 页面(默认 1 轮,可扩到 3 轮),并暴露
订阅/取消订阅/horizon/persona/重新生成 + 新场景提交等互动
操作。

该 loop 关闭后,Issue 创建时打 `lab_source = "pythia_oracle"`
标签 → 实验智能体调度(0.3.28 已实现)→ 通过
`/forecast/issue` 拉回专属预测 → 用户在预测页面订阅并迭代
场景。

## Changes

### PR-1 — Per-Issue Forecast SSE 端点

- 新增 `server/internal/handler/forecast_issue.go`:
  `POST /api/experimental/pythia-oracle/forecast/issue`
  - 请求: `{"issue_id": "uuid-or-identifier", "rounds": 1}`
  - 响应: SSE `event: prediction`,envelope 含新增字段
    `issue_id` / `scenario_context` / `lab_source`。
  - `rounds` 默认 1,上限 3,匹配 "报告轮次默认最小" 约束。
  - 通过 `loadIssueForUser` 解析 Issue,继承现有
    identifier + workspace 范围校验。
  - 当 oracle 不可用时,fall-through 到合成数据生成器,
    标记 `lab_source = "synthetic"`。

- 单元测试
  `server/internal/handler/forecast_issue_test.go`:
  - `TestIssueForecastStreamEmitsEnvelopeWithIssueID` —
    验证 SSE envelope 携带 `issue_id` / `scenario_context` /
    `lab_source` 字段。
  - `TestBuildIssueForecastContextTruncatesBody` — body
    280 字符截断契约。

### PR-2 — SSE Envelope 字段扩展

- `claude_lab_forecast.go` 中 `forecastEnvelope` 增加
  `IssueID` / `ScenarioContext` / `LabSource` 字段。
- 合成数据生成器 (`syntheticForecast`) 和 oracle 调用
  (`queryOracle`) 均设置 `LabSource = "synthetic"` 或
  `"oracle"`,renderer 通过该字段区分数据来源。

### PR-3 — Router 注册

- `server/cmd/server/router.go`: `experimental.DefaultFor(
  "pythia_oracle")` 闸门内注册 `AttachPythiaIssueForecast
  Middleware` + `RegisterPythiaIssueForecastRoutes`。
- 当 flag off 时路由物理消失(chi 不注册 404 handler),
  客户端连接失败而非误导性 200。

### PR-4 — Pythia 报告页面 + 互动操作

- 新增 `apps/desktop/src/renderer/src/components/pythia/
  pythia-report-surface.tsx`:
  - 替换 legacy 仪表盘的"全球卡片"为报告流。
  - 默认 1 轮;可经 regenerate 扩展至 3 轮,显示为分组
    区块(每轮 = 一个 section)。
  - 互动控件:
    - 订阅 / 取消订阅(SSE EventSource toggle)
    - Horizon: 天/周/月
    - Persona: 战略家/分析家/质疑者
    - 重新生成
  - 提交新场景的表单,触发 `/forecast/issue` 重发。
- 重写 `apps/desktop/src/renderer/src/pages/pythia-view.tsx`:
  - lazy-load `PythiaReportSurface` (仅当 flag 开启)
  - flag off 路径完全 bypass(空 status panel,不引入
    pythia components)。

### PR-5 — 4 语言 pythia bundle 同步

- `zh-Hans/pythia.json`: 新增 28 个中文 key(报告标题、
  互动操作文案、horizon / persona 短长描述)。
- `en/pythia.json`: 同步 28 个英文 fallback key。
- `ja/pythia.json`: 日文翻译。
- `ko/pythia.json`: 韩文翻译。
- `@multica/views` 区域 parity test 163/163 通过。
