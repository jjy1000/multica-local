## Risk vs outcome

- **Canonical packaging succeeded** — the app-builder-bin alpha.13 deadlock is
  intermittent, not guaranteed; this run got through `unpack-electron` fine.
- **verify-desktop-cold-start.sh first run failed** ("server did not bind :8090
  within 30s") — the script's own `open` was swallowed (same known hook issue
  as 0.5.1). Standalone relaunch worked; 2nd script run PASS (~2s).
- **Row-parity SQL in the verify script is broken** (psql `||` syntax error →
  always "psql-unavailable") — verified by hand instead.
- **OpenScience binary still not vendored** (pre-existing; claude_science flag
  shows 'service not bundled' — unrelated to 0.5.2).
