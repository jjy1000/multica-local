# Incident: 0.5.17 audit verification gap — 3 false positives (B1c / B2a / B2b)

**Date**: 2026-08-12 (during 0.5.17 ship audit cycle)
**Severity**: P2 (wasted agent cycles + risk of regression if "fixed" blindly)
**Versions affected**: 0.5.17 audit cycle only (no production impact — agents
prompted to verify before fixing, no regression landed)

## Summary

Three audit items listed in the 0.5.16 ship log backlog turned out to be
**stale by the time 0.5.17 agents surveyed the code**. Each was nearly
shipped as a "fix" before the agent prompt's "verify audit is current
before changing" step caught the gap.

## The three false positives

| Audit ID | Claim | Actual state | File proven |
|---|---|---|---|
| **B1c** | `user_plugin` 缺 zh-Hant 49 键 | `SupportedLocale` is a 4-lang union by design; `matchLocale(["zh-Hant"]) → "zh-Hans"` is a pinned test (zh-Hant collapses intentionally, NOT a missing locale) | `packages/views/i18n/locale.ts::matchLocale` |
| **B2a** | `claude_science` Chat tab 真研究模式 缺 | `LabChatPanel` already exists since 0.3.40 at `packages/views/experimental/components/lab-chat-panel.tsx` | `packages/views/experimental/components/lab-chat-panel.tsx` |
| **B2b** | `user_plugin DEFAULT_TABS` 需扩 5 种 | Already 6 kinds (`artifacts / chat / table / iframe / code / settings`) at `plugin-shell-view.tsx:59` | `packages/views/experimental/components/plugin-shell-view.tsx:59` |

## Pattern

When delegating audit items to fix agents, the agent prompt MUST include
a **"verify audit is current before changing"** step:

1. Read the file paths cited in the audit.
2. Search for the component / locale / config the audit says is missing.
3. STOP if the gap is already closed by an earlier ship.

Do **not** silently "fix" something that is already correct. That wastes
an agent and risks regression — a "fix" that adds a second `LabChatPanel`
or a 5th `DEFAULT_TABS` kind would land a real bug to close an
imaginary one.

## Why this matters for 0.5.18+

The 8 fork-applicable HIGH vuln (`F-002 / F-005 / F-006 / F-007 / F-008 /
F-013 / F-027 / F-028`, see `.omc/audit/2026-08-05-vuln-scan/triage.md`)
are a similar shape — **sourced from static analysis + a few flagged
"design tradeoffs" (F-007, F-008)** that may be deliberate rather than
vulnerable. Before porting each fix, agents must read the cited file +
the relevant CLAUDE.md section to confirm the gap is real and the fix
matches intent.
