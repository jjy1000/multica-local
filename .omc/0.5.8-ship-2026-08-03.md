# 0.5.8 ship log — 2026-08-03

## Summary

`API Error: API returned an empty or malformed response (HTTP 200) — check for a
proxy or gateway intercepting the request` no longer falls through to
`agent_error.unknown`. The Anthropic SDK error class names
(`EmptyResponseError` / `APIConnectionError`) and the user-facing message
substring (`empty or malformed response`) are now classified as
`ReasonAgentProviderServerError`, which puts the task back on the retry
allowlist. Also restored the fork's `server/pkg/redact` package source that
`internal/handler/daemon.go` and `internal/service/task.go` already import
(0.5.6 cleanup had deleted the source but left the imports — separate leak
path for `Authorization Bearer ...` / API keys / home paths landing in
`agent_task_queue.error`).

## Risk

- **Low** — the new classifier rule is a string-substring match appended inside
  case 6 (provider 5xx / server error), which already exists in
  `taskfailure.Classify`. The new rule cannot shadow any earlier case (1–5
  are: context overflow, missing config, auth/access, quota, capacity — all
  keyword sets are disjoint from `empty or malformed response` /
  `emptyresponseerror` / `apiconnectionerror`). All 80+ existing
  `TestClassifyRules` / `TestClassifyOrderingPriorities` /
  `TestClassify5xxRegex` / `TestClassifyAlwaysReturnsAgentSide` fixtures
  still pass.
- **Medium** — `pkg/redact` restoration is technically a separate concern
  from the classifier fix, but the build *would not compile* without it
  (handler/daemon.go and service/task.go import it but the source was
  missing). Including it here is necessary; releasing without it would
  leave the build broken. The restored source is byte-for-byte identical to
  upstream `multica-main@multica-main 2` — no fork-local patches.

## Out of scope (recorded for 0.5.9)

- `IdleWatchdogTimeout` / `HandshakeTimeout` / `ResumeExpected` on
  `pkg/agent.ExecOptions` — would harden the daemon against the same root
  cause (gateway killing the connection) by letting the child process exit
  cleanly when the upstream is dead. Requires touching claude / codex
  backend stdin/stdout protocol layer; scope creep for 0.5.8.
- `server/internal/selfexec` — upstream has it, fork has neither source nor
  importer. No-op for this release.

## User-visible behavior delta

Before 0.5.8:
```
Dashboard → issue assigned to agent → task fails →
  error: API Error: API returned an empty or malformed response (HTTP 200) —
  check for a proxy or gateway intercepting the request
  failure_reason: agent_error.unknown
  retry: never (reason not on allowlist)
  user action required: manual retry
```

After 0.5.8:
```
Dashboard → issue assigned to agent → task fails →
  error: API Error: API returned an empty or malformed response (HTTP 200) —
  check for a proxy or gateway intercepting the request
  failure_reason: agent_error.provider_server_error
  retry: yes (on the server-side retry allowlist)
  user action: none unless retry budget exhausted
```

Additionally (collateral fix from `pkg/redact` restore):
any agent stderr containing `Authorization: Bearer mat_…` / `sk-…` API keys /
`/Users/jiangjianyan/...` home paths is now scrubbed before reaching
`agent_task_queue.error` and the WebSocket broadcast.
