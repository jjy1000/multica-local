## Lessons / prevention

1. **audit 验证不能跳过**。B1c (zh-Hant) + B2a (Chat/Knowledge) + B2b (DEFAULT_TABS) 都是 audit 误报,先验证再动手避免做无用功 — 每个 agent 都被 prompt 要求"先确认 audit 是否成立,再决定"。
2. **Packaging 必须从 `apps/desktop/` 跑**。0.5.16 已经记录过这条(0.5.9 ship blocker),本 ship 第一轮从 repo 跑直接撞到 `multica-main` (旧项目名) 绝对路径 stale symlink。从 apps/desktop 跑通过。**Future ships: 把这个写进 ship-mac.sh 强制 cwd 检查。**
3. **scope discipline 仍生效**。LabOutputPanel / iframe auth proxy 真缺但无 spec,本 ship 跳过,留 design doc 任务给后续 — 不造组件、不发明 endpoint 是稳定为主的硬约束。
