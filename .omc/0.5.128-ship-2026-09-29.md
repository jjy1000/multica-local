## 批 2 — 删除 tombstone 化（用户反馈: "误删 opencode 后重加回来导致智能体消失"）

**旧行为两破坏点（读码实锤）**:
1. DeleteAgentRuntime / ArchiveAgentsAndDeleteRuntime **硬删归档 agents + 行** →
   daemon 重注册铸**新 id** 行 → 智能体永远回不来。
2. task_usage_hourly.runtime_id **无 FK**——用量行不删但成孤儿, 新 id 接不上
   （"token 消耗记录消失"真身; 注意 runtime_usage 表 046 已 DROP, 032 task_usage 挂 task_id）。

**tombstone 契约**: 删除只打 `metadata.deleted_at`（级联端点另记
`deleted_archived_agent_ids` = 本次删除归档的 ids; archive/cancel/pause 保留;
squads/agents 硬删步骤移除——没有行被删所以 squad.leader FK 不再阻碍）→ 列表查询过滤
tombstone → **UpsertAgentRuntime 的 UNIQUE(workspace,daemon,provider) 仲裁器复用同一行
id** → DaemonRegister 内置分支 upsert **前** `tombstoneSnapshot` 抓 ids（upsert 的
`metadata=EXCLUDED.metadata` 覆盖正是清标记动作）→ upsert 后
`RestoreAgentsArchivedByRuntimeDeletion` 恢复 + 逐个广播 agent:restored。agent 绑定
（FK RESTRICT）与用量历史**从未断开**。复活以 daemon 实际重注册为准。删默认运行时 FE 清
default_runtime_id 键（防复活静默续任默认）。custom-profile 级联（runtime_profile.go）
保持硬删未动; legacy merge 不受影响。

**测试坑**（三条都踩了）:
- fixture runtime 行 daemon_id 为 NULL 时 UNIQUE 仲裁器永不命中（NULL≠NULL）——
  revival 测试必须先 UPDATE daemon_id 再 snapshot/upsert。
- jsonb 数组转 uuid[]: `jsonb_array_elements_text($1::jsonb)::uuid`
  （`jsonb_array_elements` 产出 jsonb 不能直接 ::uuid → 42846）。
- `runtime_usage` 表已不存在（046 DROP）——usage 夹具改用 `task_usage_hourly`
  （agent_id NOT NULL, 夹具要传 agent id）。

**旧钉反向重写**（把硬删当基线钉着）:
`TestArchiveAgentsAndDeleteRuntime_HappyPath`（旧行=删+agent 删）/
`TestDeleteAgentRuntime_RemovesArchivedSquadsLedByArchivedAgents` / `NoSquadsRegression`
→ tombstone 契约（行保留+标记、agent 保留归档、task_usage_hourly 保留、列表不可见）。
新增 `TestDeleteAgentRuntime_LightPathTombstones`（既有归档不复活）+

### 第一次尝试: ✗ electron-builder 下载 EOF（0.5.102/0.5.107 同族, 第 4 次）

```
⨯ Get "https://github.com/electron/electron/releases/download/v39.8.7/
  electron-v39.8.7-darwin-arm64.zip": EOF
✗ electron-builder failed — aborting
```

`~/Library/Caches/electron/` 是空的（当日早些时候被清）。0.5.107 的 ~/.npmrc
proxy=null 毒已除, 这次是纯网络抖动（github releases 大文件掐断）。

**解法（比等重试稳）**: npmmirror 镜像预热缓存后重跑——

```sh
curl -sL -o ~/Library/Caches/electron/electron-v39.8.7-darwin-arm64.zip \
  https://npmmirror.com/mirrors/electron/v39.8.7/electron-v39.8.7-darwin-arm64.zip
# 112MB, sha256 86fa117b…; 然后直接重跑 ship-mac.sh --yes
```
