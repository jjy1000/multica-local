## Ship path

```
# 1. Snapshot — .app 0.5.0 backup + 13 tables + 80 config + 6839 KB vaults
bash ~/.multica/scripts/pre-update-snapshot.sh            # exit 0
# 2. migrate up — all skip (already applied), DB at 227
cd server && go run ./cmd/migrate up
# 3. bundle-cli — 3 binaries rebuilt at 0.5.1 + Pythia/OpenScience/claude-science
pnpm --filter @multica/desktop bundle-cli
# 4. electron-vite build — 1.29s
pnpm exec electron-vite build
# 5. electron-builder --dir — FAILED (known app-builder-bin alpha.13) → fallback
# 5.1 manual asar repack (validated twice before)
asar extract /Applications/Multica.app/Contents/Resources/app.asar /tmp/multica-extract
rm -rf /tmp/multica-extract/out/{main,preload,renderer}
cp -R apps/desktop/out/{main,preload,renderer} /tmp/multica-extract/out/
cp apps/desktop/resources/bin/{multica,server,migrate} /tmp/multica-extract/resources/bin/
asar pack /tmp/multica-extract /tmp/multica-new.asar        # 513M
# 5a. deploy (user-confirmed) + Info.plist + re-sign
cp /tmp/multica-new.asar /Applications/Multica.app/Contents/Resources/app.asar
cp apps/desktop/resources/bin/{multica,server,migrate} \
   /Applications/Multica.app/Contents/Resources/app.asar.unpacked/resources/bin/
defaults write ... CFBundleShortVersionString 0.5.1 ; defaults write ... CFBundleVersion 0.5.1
bash scripts/desktop-sign-nested-binaries.sh /Applications/Multica.app   # exit 0
# 6. cold start + verification (below)
```

Note: the first cold-start attempt was silently skipped — the `open` command
was swallowed by a context-mode curl hook in the same shell command; re-launched
standalone, then all checks green.
