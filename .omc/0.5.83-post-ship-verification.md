## 3. Confirmed bugs (fix-first list for 0.5.84; items 1–2 re-verified by hand)

1. **`FLAG_ROUTE_SUFFIX` missing the `causal_graph` entry** —
   `packages/views/issues/components/issue-labs-section.tsx:30-55` has no
   `causal_graph: "causal-graph"` row → issue lab-picker external links / PropRow /
   create-issue redirect for this lab silently no-op. Same trap semantica hit in 0.5.81
   (the file's own comment warns about it).
2. **`createCausalSuggestion` lacks the never-nag probe** —
   `server/internal/handler/causal_graph.go:707-781` never calls `FindCausalEdgeBetween`
   (the probe exists only on the manual path `createCausalEdge:580-587`; the partial
   unique index covers active rows only) → an LLM posting the same (from,to,type) triple
   repeatedly yields duplicate `suggested` rows. Client skill discipline is the only
   guard today.
3. **30-day stale TTL hides Tier A chains** — `TouchCausalNode` has zero callers, so
   `last_observed_at` is frozen at creation; after 30d every action/outcome/decision node
   goes `stale` while subgraph seeds filter `status='active'` → the chain vanishes from
   the UI and chain-linking degrades to root stars. (`maintenance.go:8-9` documents "no
   callers yet".)
4. **Maintenance ticker never fires under daily restarts** — in-process
   `time.NewTicker(24h)` with no DB anchor (`maintenance.go:120-132`); the desktop server
   restarts daily, so sweeps may never run (which currently also masks bug 3 — and also
   disables suggested-row GC). Evolver is immune (audit-row window + catch-up).
5. **Workspace graph mixes statuses with no visual distinction** —
   `useCausalWorkspaceGraph` (`causal-graph-queries.ts:122-124`) doesn't pass `status`,
   handler only filters when asked (`causal_graph.go:493`), and `EDGE_TONES` keys by type
   only → suggested/rejected render identical to active. Subgraph endpoint is active-only
   — the two surfaces disagree.
6. **BFS ring-layout angle bug** — `causal-minimap.tsx:94` divides by pre-insertion
   count+1 instead of the ring's final size → uneven angular spread that worsens with
   node count.
7. Smaller: probe-then-insert race can orphan nodes without edges (recorder returns
   without edge on unique-index loss); `causal-graph-queries.ts` comments promise a 60s
   idle backoff and 404-degrades-to-undefined, neither matches the code; 5 reserved i18n
   keys unreferenced; web full-graph page remains a stub (desktop-first), `?run=` deep
   link not wired into the causal graph view.
