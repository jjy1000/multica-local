```python
def call_local_llm(prompt: str, system: str = "") -> dict:
    """0.3.16+: LLM 路由归 Multica 端。Python 仅把 prompt + system 打包成
    HTTP POST JSON 给 loopback Multica agent runtime(PythiaManager 注入
    MULTICA_AGENT_RUNTIME_URL)。Multica 端用自家 provider chain,模型配置
    由用户在 Settings → 模型 设定。Python 服务不再 spawn Ollama / 不再
    本地加载 model。
    """
    url = os.environ.get("MULTICA_AGENT_RUNTIME_URL", "").rstrip("/")
    if not url:
        raise RuntimeError("MULTICA_AGENT_RUNTIME_URL not set; pythia-manager injects it")
    r = httpx.post(f"{url}/api/runtime/llm-call",
                   json={"prompt": prompt, "system": system}, timeout=240)
    r.raise_for_status()
    return r.json()  # {"text": "...", "model": "..."}
```

## Phase E — Mythos Swarm(蜂群 agent 拓扑)

### E0. 设计原理

OpenMythos 的核心架构是 **RDT(Recurrent-Depth Transformer)**:Prelude(输入编码)→ Recurrent Block(迭代 N 次,深度可调)→ Coda(输出合成)。这跟 Multica 现有 squad 拓扑高度同构。映射:

| RDT 组件 | Multica squad 实现 |
|---|---|
| Prelude(prelude_layers 个 transformer block) | 1 个 `mythos_prelude` squad leader agent + 1 个主 issue |
| Recurrent Block(loop N 次) | N 个 `mythos_loop_N` squad member agent,并行处理 sub-issue,每次迭代创建新 sub-issue,直到 `spectral_radius < 1.0`(收敛判据)或达 max_loop_iters |
| Coda(coda_layers 个 transformer block) | 1 个 `mythos_coda` squad member agent,汇总所有 loop 输出 |
| MoE(n_experts + n_shared + n_experts_per_tok) | 每个 loop member 选 2 个 experts(skill 调用)从 `experimental_resource_lock WHERE experimental_source='claude_science'` 取 |
| Adaptive Computation(max_loop_iters) | squad 配置 `max_loop_iters`,默认 16(Mythos 1B 设定)|
| Spectral Radius ρ(A) < 1 | 收敛判据:sub-issue 答案与上一轮 token-level cosine similarity ≥ 0.95 视为收敛 |

## 风险登记

| # | Risk | Mitigation |
|---|------|-----------|
| 1 | Pythia 删 Ollama 后 `ask_oracle` / `predict_now` 性能差(网络 round-trip 1 次) | runtime llm-call endpoint 走单次 provider chain,实测 < 200ms 网络 + 模型调用并行;预测一次走 LOOP 异步,不卡 world_brief |
| 2 | OpenScience prompts vendor 进 DMG 后 290 个 .txt 文件被 electron-vite 误打包 | 明确路径 `resources/openscience-prompts/`,在 `electron-builder.yml::files` 显式 include,不在 `apps/desktop/src/` 下,electron-vite 不动 |
| 3 | Pythia Python venv 不在 DMG → 首启需要用户跑 pip | install handler 返回 503 + 明文提示「pip install -r pythia/requirements.txt」,不是 ENOENT crash。0.3.10 memory contract 复用 |
| 4 | Claude Science Multica-native UI 工作量大(291 skills 详情页) | Phase B 分 5 sub-PR:skeleton / list+search / detail+markdown / category filter / issue-create 入口。任意 PR ship 都能用 |
| 5 | `runtime/llm-call` HTTP 端点暴露给本地服务后被滥用 | source_ip=127.0.0.1 strict + 限频(默认 60 req/min)+ token-only auth;不在 `~/.multica/scripts/` 加 zsh helper 避免误用 |
| 6 | Mythos Swarm 多 agent 并发 → agent_task_queue 拥塞 | 默认 max_loops=16,concurrent_loop_members=3,加 rate limit 60/min/run;并发上限由 squad 配置,runner 单实例不并发(每次 run 独立) |
| 7 | Mythos convergence 永不收敛 | hard cap max_loop_iters=48(Mythos 1B 上限);若 48 仍未达 cosine 0.95,直接进入 coda 用最后轮 |
| 8 | Mythos 跟用户 squad 复刻 | install handler 不 mutation 现有 squad;只创建 Mythos 自己的;用户 squad 由未来清扫工具决定 |
