## Notable findings this release

1. **`AllSources` allowlist bug (latent S1)**: `SourceCausalGraph` existed but `experimental.AllSources` didn't include it, so `Claim` rejected every install with "unknown source". Latent through S1 because the REST surface never calls Claim — caught immediately by `TestInstallCausalGraphSeedsHiddenTeam`. New standing rule: every new `Source` constant must join `AllSources` in the same commit; pinned by `TestAllSourcesContainsCausalGraph`.
2. **Reject-as-delete broke ICP-5**: tier-D proposers re-derive proposals from current state, so hard-deleting a rejection would re-propose it nightly. Mig 280 turned rejection into a `status='rejected'` tombstone (audit trail + never-nag anchor); proposers probe `FindCausalEdgeBetween` (any status) before writing.
