## Ship path

**This ship is a git-only release** — no `.app` rebuild, no DMG, no
binary swap. The user explicitly approved scope "仅补足 Phase 1 (迁移 +
cloud 中和), 不动 Phase 2/3" and did not request a 0.4.0 desktop
ship. The git branch `epic/0.4.0-integration` now carries the 0.4.0
fork release baseline. A future 0.4.0 desktop ship would:

1. `bash ~/.multica/scripts/pre-update-snapshot.sh` (mandatory).
2. `cd server && go run ./cmd/migrate up` (no-op — wave 2 already
   applied).
3. `pnpm --filter @multica/desktop bundle-cli` (build Go binaries at
   version=0.4.0).
4. `pnpm --filter @multica/desktop build` (electron-vite).
5. `pnpm exec electron-builder --mac --dir` (pack — expect 0.3.67-style
   deadlock; use manual asar-repack fallback if needed).
6. `bash scripts/desktop-sign-nested-binaries.sh /Applications/Multica.app`.
7. `bash ~/.multica/scripts/verify-desktop-cold-start.sh`.
