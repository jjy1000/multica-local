## Follow-up queue skip — rationale

The 5-commit cluster (#6418/19/30/31 + #6444, MUL-5750/5751/5760) was
analysed by **4 parallel explore agents** before skipping. Every agent
independently confirmed the fork's chat is a deliberate single-task model:

- `packages/core/chat/pending.ts` — MISSING (the queue state machine)
- ChatQueue / chat-page.tsx / use-chat-controller / use-chat-task-actions —
  ALL MISSING
- `ChatPendingTask` = 3 fields, no `supports_queue`/`queued_tasks`/`queued`
- server: no `ListPendingChatTasksForSession`, `DirectChatSendResult`,
  `SendDirectChatMessage`, `PrioritizeQueuedChatTask` — 7 plumbing pieces
  absent; `channel_ingested` column absent
- migration 255/256 reference upstream's v2 index (fork has only v1 from
  migration 040)

Porting = rewriting a 1000+ line subsystem. Violates the fork contract
"do NOT re-add deliberately simplified features". The task-status-pill
`deferred`/`retrying` subset is extractable but dead code today
(`GetPendingChatTask` excludes `deferred`). Full analysis in memory
`chat-followup-queue-fork-absent-2026-08-06.md`.
