### 本 ship 新增教训（下次发版前重读）

1. **`~/.npmrc` 的 `proxy=null`/`https-proxy=null` 是 electron 下载毒药**：
   app-builder 把字面量 "null" 当代理 URL 解析 → `proxyconnect tcp: dial tcp :0`
   （端口为空）。已注释删除（2026-09-17）。npm 自己不报错，只有 electron-builder
   下载期爆——极难联想到 .npmrc。
2. **系统代理实为 127.0.0.1:7893**（`scutil --proxy`），非 7892；7892/7893 对
   github TLS 都半死，但 npmmirror 直连秒下（112MB electron zip 直连约 1 分钟）。
   ship 时用 `env -u http_proxy … -u ALL_PROXY ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。
3. **bundled PG 不随 daemon 存活，只随 app 存活**：app 没开时 migrate 步骤直接
   abort（本次首跑即栽在这）。救场：`/opt/homebrew/opt/postgresql@17/bin/pg_ctl
   -D "$HOME/Library/Application Support/Multica/pgdata" -l …/pg/pg.log start`，
   手动拉起不被验证器 pkill 命中。
4. **管道吃退出码第 3 次踩坑**：`bash ship … | tail` 让 abort 的 ship 看起来
   exit 0。必须 `> log 2>&1; rc=$?`。
