## Lessons

- **Always verify pre-existing failures before fixing**: checkout parent
  commit and reproduce it. Avoid the 0.5.17 trap (fix an audit item that
  was already correct).
- **`git checkout X -- path/` corrupts working tree** when X is in the
  middle of a multi-commit chain — sibling files don't update, breaking
  the build. Use `git clean -fd` to recover and re-apply fixes on HEAD's
  version.
- **Mock `s.queries` is too narrow**: the seam added for the 0.3.64
  supervise completion test handles `GetMythosRun`/`GetIssue` but
  `issuestatus.Effective` calls `s.queries` (not the seam) for custom
  statuses. To test custom-status terminal behavior, `Service.queries`
  needs to become an interface.
- **Document audit in `.omc/release-notes-X.md`**: the per-resolution
  breakdown (which file, what conflict, which side won, why) is the
  single source of truth for "why does this file look like that?".
