## 风险 vs 结果

- **catalog literal 删除**: 任何 `experimental.DefaultFor("agent_creation_studio")` / `experimental.DefaultFor("agent_self_optimization")` 调用现在返回 false(未注册);但 0.5.5 之后没有任何 active 调用点,全 0 引用
- **install handler 删除**: `multica experimental install agent_creation_studio` / `multica experimental install agent_self_optimization` 现在 404(router 不再注册);legacy CLI 调用会失败。0.5.5 之后用户不再走这条路径(Labs tab 无 toggle),所以无影响
- **self-opt view 删除**: 任何 bookmark `/experimental/agent-self-optimization` 现在跳到 NotFound 页面;0.5.5.3 ship 后 user 看到的"已升格为产品内置"提示仍有效,但没 view 渲出来。这是预期 trade-off(完整拆解,view 移除)
- **migration 237 destructive**: DELETE 是 destructive;down 是 no-op,recover 必须 downgrade + re-install flags。0.5.6 是 forward-only 路径,down 不常见
- **agent_subscriber dispatcher 路径保留**: 0.5.5.1 解的 9 个 `false &&` 短路改 always-reachable(handler 总可用);同 0.5.6 行为一致
