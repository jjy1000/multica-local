# 0.5.109 — 2026-09-19(上游价值移植批:daemon 可靠性 + 流式体验)

上游 `9e7e529b7` 之后 22 个新提交,三路深挖后 **12 移植 / 10 跳过**(证据在
[upstream-sync-2026-09-19.md](upstream-sync-2026-09-19.md))。本批主题:任务终态
的可靠性(不再永久卡"进行中")+ 回复流式到达 + 中文输入提及可达。

## 可靠性(最重要)

- **任务终态回调持久化重放**(MUL-7471):daemon 的完成/失败回调现在先落盘再
  发送,server 短暂不可达(DB 宕机、401 风暴、进程崩溃、断电)期间丢失的回调
  会在恢复后自动重放——此前这类丢失会让任务**永久卡在"进行中"**(0.5.108 的
  PG 事故当天就暴露过这个损失类)。配套:已终结的任务重复收到完成回调时,不再
  重放评论/通知等事务外副作用。
- **Pi 静默错误显式化**(MUL-7467):Pi 某轮报错但进程退出码为 0 时,以前会被
  记成"成功+空输出";现在轮末的错误状态被解析并让任务失败,取消时也保留真实
  的 provider 错误而不是笼统的 "aborted"。挂住的错误轮在宽限期后收敛为失败。
- **hermes 关闭有界化**(MUL-5241):逃逸的子进程持有管道时,以前 reader 永久
  join 卡死整轮对话;现在关闭路径 10 秒有界。
- **Cursor 网络错误正确分类**(afedc6f76):`connect etimedout` 类错误以前落进
  进程失败桶,现在正确归入 provider 网络错误。

## 流式与输入体验

- **Codex 回复逐字流式到达**(MUL-7465):此前 Codex 一轮要等全部完成才整块
  出现;现在 delta 端到端流式,首段内容毫秒级进入对话记录(实测首轮 ~2-60ms)。
- **提及(@)在中文后可用**(MUL-7456):以前只在半角空格后才能唤出提及选择器,
  中文输入几乎不可达;现在任意 token 边界(含 CJK、标点、全角空格)都能唤出。
- **阶段进度区分"已取消"**(MUL-7449+7485):父任务的阶段摘要以前把已取消的
  子任务计成"完成",误导后续 agent 决策;现在分开计数,并在推进指引里给出
  带数量的取消警告。
- **自动化排程可再编辑**(MUL-7478):"1 个时间表 + 1 个 webhook"组合以前把
  时间表永久锁死;现在只锁真正的多时间表(≥2),且锁定提示如实说明需要删除
  后重建。
- **@all 说明**(MUL-7447):评论中提及 @all 时显示说明 chip——@all 只通知
  成员,不会启动智能体。
