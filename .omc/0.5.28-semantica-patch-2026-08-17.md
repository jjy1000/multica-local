## Lessons (for next mythos cycle)

1. **Audit-then-decide**. The original audit surfaced 5 issues; 4 had plausible "ship as 0.5.28" reads (P0-1, P0-2, P1-1, P1-3). Only after R4's security pass did 4/5 collapse — that's the value of the security-reviewer step. Without R4, A would have shipped and created two regressions (F-005 reopened by P0-1, F-013 class re by P1-1). Don't skip the red team.
2. **Architect's file paths are aspirational**. R2 proposed `server/internal/semantica/` — the directory does not exist. R3 read the actual file tree and rerouted 2 of 5 file paths. If R3 hadn't run, the steelman plan would have shipped to wrong files.
3. **Verifier evidence > verifier opinion**. R6 INCONCLUSIVE on P0-1 (couldn't verify the 60-180s claim from in-repo sources). Routed the verification through the D script instead of deferring — that closes the loop without external docs.
4. **Synthesizer is the only role allowed to override prior rounds**. R5 demoted R2's A=top-1; R6 confirmed R4's evidence; R7 reconciled. Without that explicit override right, A would have shipped with a security regression.
