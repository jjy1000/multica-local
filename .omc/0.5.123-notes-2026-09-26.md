# 0.5.123 用户可见变更 — 2026-09-26

安全加固为主的一版，全部本地化行为、无云依赖变化。零迁移，数据不动。

## 安全

- **Pythia 推演引擎不再裸奔**：引擎 loopback HTTP 现在要求 token（桌面主进程自动生成注入，用户无感知）。`/health` 之外所有端点未带 key 一律 401；本机其它进程从此无法驱动推演/改配置。`multica pythia` CLI 在 agent 任务和裸终端里都照常工作。
- **provider CLI 子进程不再继承服务端密钥**：LLM 调用拉起的 claude/codex 等子进程只拿到 PATH/HOME/代理与 provider 凭证，不再见到 DATABASE_URL、JWT、平台 token。
- **用户插件 subprocess manifest 参数加固**：含 shell 元字符的 args 直接 400 拒绝。
- **飞书安装授权纵深**：三处校验补齐（路由本就 admin-only，属纵深）。
- **claude-science 技能脚本加固**：SQL 工具所有插值走转义 helper；奖励执行环境的 builtins 剔除全部 dunder（堵 `__loader__` 导入逃逸）。

## 修复

- **autopilot/渠道建的 issue 现在会出现在活动时间线**（此前静默丢失 "created" 记录——与上游同款 bug，已修）。
- 取消 chat 任务不再把整个会话 transcript 拉进内存（大数据量时取消明显更快）。
- 法语界面 run-confirm 对话框不再出现横向滚动条。
- `multica lab delegate` 相关 CLI 测试基线更新到 0.5.122 retirement 后的目录（cmd/multica 测试全绿）。
