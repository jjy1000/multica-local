# 0.5.5.1 Ship Log — 2026-08-02

**Version**: 0.5.5.1 (`apps/desktop/package.json`, Info.plist verified 0.5.5.1)

**Type**: self-opt 彻底脱离实验域

## 内容

### self-opt 全面升格为产品内建(0.5.5 只做了一半)

**0.5.5** 改:`agent_creation_studio` + `agent_self_optimization` 的 **install 路径** + leader agent 的 **boot provision**,但 self-opt 的 flag gate、handler gating、install handler、visibility hide 仍走实验域。

**0.5.5.1** 进一步:**self-opt 的 6 个层面完全脱离实验域**:

| 层面 | 0.5.5 | 0.5.5.1 |
|---|---|---|
| 1. catalog Flag `DefaultVal` | `false`(用户手动 enable) | **`true`**(产品级) |
| 2. self-opt service flag gate (`flagOnForUser`) | 读 `experimental_pref` 行 | **stub 永远返回 true** |
| 3. scheduler ticker | per-(opted-in user, workspace) cross-product N×M | **per-workspace 1 个 ticker** |
| 4. `self_opt_edits.go` 5 个 `experimentalFlagEnabled` gate | flag off → 404 | **全解(handler 总是 200)** |
| 5. `agent_trust.go` 4 个 `experimentalFlagEnabled` gate | flag off → 404 | **全解(handler 总是 200)** |
| 6. install handler (`multica experimental install agent_self_optimization`) | 注册在 router,user 走 CLI 调 | **保留(legacy compat)**,user 不会走(Labs tab 无 toggle) |

### 用户视角的体验

- **自动化工程页**:`SkillOpt-Multica 每日 00:00` + `智能体工程师团队 每3工作日` 显示为普通 autopilot
- **用户控制**:`multica autopilot update --disabled` 关闭某条 cadence —— **真正的 user control point**
- **不再需要**:Labs tab toggle、`multica experimental install agent_self_optimization`、opt-in pref 行
- **`智能体优化专家` agent**:跟其他 agent 平级,AssigneePicker 直接选,无 `lab_managed` 标记

- **`false &&` 短路模式**:故意保留 `experimentalFlagEnabled` 调用(短路掉),这样未来如果需要回退 flag gate,只改 false → true,不需要重新写 `if` 块
- **stub 函数签名保留**:`flagOnForUser` 仍接受 `PrefQuerier` 参数,即便内部不再使用,signature 不变,call site 不动 —— 0.3.45.1 时代的 import 不破
- **ListOptedInUsers query 保留**:sqlc query 仍存在,只是 service.Start 不再调;未来如果要"per-user 暂停"功能可复用
- **0.5.5 阶段的 bug 修复沿用**:`upsertAgentCreationExpert` synthetic stub fallback 在 0.5.5.1 也起效(本次没改)
